# Service-Desk-Back

## Description
A simple backend application to train myself with Node and [Nest](https://github.com/nestjs/nest). Functionally, the application will allow to create and see demands and interact with them as a user, operator, and responsable.


## Project setup
Download the project 
```bash
$ git clone https://github.com/MahmoudEllouze91/Service-Desk-Back.git
$ npm install
```

## Compile and run the project

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
